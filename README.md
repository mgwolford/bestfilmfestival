# Best Film Festival 🎬

Best Film Festival is a React-based movie bracket experience that helps users discover and compare films from different genres, categories, and years.

Users can select a category, generate a randomized collection of films, and vote through head-to-head matchups until a personal champion is crowned.

## Live Site

https://mgwolford.github.io/bestfilmfestival/

## Features

* Browse movies by category and year
* Movie data powered by The Movie Database (TMDB) API
* Randomized film matchups
* Interactive tournament-style bracket experience
* Poster artwork and movie details
* Mobile-friendly responsive design
* Limited reroll system for fresh matchups
* Clean single-page user experience

## How It Works

1. Click **Begin Festival**
2. Select a movie category and year range
3. Receive randomized film matchups
4. Choose your favorite film in each round
5. Use rerolls strategically to refresh a matchup
6. Continue until one film remains
7. Discover your Best Film Festival Champion

## Installation

Clone the repository:

```bash
git clone https://github.com/mgwolford/bestfilmfestival
```

Navigate into the project:

```bash
cd best-film-festival
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
